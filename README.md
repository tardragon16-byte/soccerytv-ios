# Soccery TV for iOS

Soccer TV HD Live Football Stream app wrapper for iOS (SwiftUI + WKWebView).

## Features
- Fullscreen WebView for soccerytv.com
- Pull-to-refresh & Progress bar
- Native League list with search
- Settings & Theme support
- Auto-built via GitHub Actions into `.ipa`

## GitHub Actions Automated Build
Every push to `main` builds `SocceryTV.ipa` automatically.
Download the `.ipa` from the **Actions** tab under **Artifacts** and sideload using **Sideloadly** or **AltStore**.
